# HomBot Lovelace examples

These files are manual examples. They do **not** install frontend resources, change your dashboard, or contact the robot.

No custom Lovelace cards are required. The example uses only built-in cards.

## Prerequisites

1. Install or update the `lg_hombot` custom integration.
2. Restart Home Assistant and confirm these entities exist for your robot:
   - a vacuum entity
   - a battery sensor entity
   - a camera entity named **Camera**
   - a Repeat switch
   - a Cleaning pattern select
   - a Learned map image
   - a Cleaning route select
   - a Route image

## Entity IDs

Entity IDs are generated by Home Assistant from the configured name and unique ID. Unique IDs include the configured HomBot URL, so they differ between installs.

In **Developer Tools → States**, find the entities on your HomBot device and copy their IDs.

In `hombot-vacuum-camera-card.yaml`, replace:

| Placeholder | Example |
|---|---|
| `REPLACE_VACUUM_ENTITY` | `vacuum.hombot` |
| `REPLACE_CAMERA_ENTITY` | `camera.hombot_camera` |
| `REPLACE_BATTERY_ENTITY` | `sensor.hombot_battery` |
| `REPLACE_REPEAT_ENTITY` | `switch.hombot_repeat` |
| `REPLACE_PATTERN_ENTITY` | `select.hombot_cleaning_pattern` |
| `REPLACE_MAP_ENTITY` | `image.hombot_map` |
| `REPLACE_ROUTE_SELECT_ENTITY` | `select.hombot_cleaning_route` |
| `REPLACE_ROUTE_IMAGE_ENTITY` | `image.hombot_route` |

## Add the card manually

1. Open your Lovelace dashboard.
2. Edit the dashboard and choose **Add card** → **Manual**.
3. Paste the contents of `hombot-vacuum-camera-card.yaml` after replacing the placeholders.
4. Save.

Alternatively, store the YAML under your dashboard configuration if you maintain dashboards as files.

## What the card shows

- Status, battery percentage, charging state, and a camera still
- Start, pause, stop, and return to dock
- Fan speed (`Turbo` / `Normal`) via `vacuum.set_fan_speed`
- Repeat, using the Repeat switch
- Cleaning pattern, using the Cleaning pattern select (Zigzag or Cell by cell)
- Learned map and historical route, side by side
- The Cleaning route select
- Read-only status details: fan speed, cleaning mode, repeat, last cleaning, nickname, firmware, and total cleanings

`repeat_mode` and `cleaning_mode` on the vacuum stay read-only. `repeat_mode` follows `JSON_REPEAT`. `cleaning_mode` is the raw `JSON_MODE` value. The switch and the Cleaning pattern select change those modes.

## Learned map and historical route

The learned map is the stored floor map. It does not require a selected cleaning run.

The route image is one past cleaning. Select a run in **Cleaning route** first. Until you do, that image has no picture. It is not the learned map.

## Camera behavior

The camera entity serves still JPEG snapshots when Home Assistant asks for an image. That is not the same as a continuous live stream. Do not add a fast automatic refresh until you have measured the load on your robot and Home Assistant.
